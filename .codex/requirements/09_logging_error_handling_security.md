# 09. ログ・エラー処理・安全要件

## ログ要件

すべての処理を `logs/install.log` に記録する。

ログに含めるもの：

- 開始時刻
- 実行ユーザー
- 管理者権限の有無
- 実行ディレクトリ
- OS情報
- PowerShellバージョン
- 各必須ファイルの存在確認結果
- 各ファイルのSHA256値
- 実行したコマンド
- 終了コード
- スキップ理由
- エラー内容
- 完了時刻

## 個別ログ

MSIなどがログ出力できる場合は以下へ出す。

```text
logs\node-install.log
logs\sourcetree-install.log
logs\vscode-install.log
logs\codex-install.log
```

## エラー処理

- `$ErrorActionPreference = "Stop"` を設定する。
- 例外はトップレベルの `try/catch` で捕捉する。
- エラー発生時は `logs/install.log` に詳細を書く。
- 失敗した処理名を表示する。
- 終了コード `1` で終了する。

## MSI終了コード

原則：

| 終了コード | 扱い |
|---:|---|
| 0 | 成功 |
| 3010 | 成功。ただし再起動が必要 |
| その他 | 失敗 |

## 安全要件

- ローカルに存在しないインストーラーをネットから自動取得しない。
- 任意URLを実行しない。
- 不明なEXEを列挙して自動実行しない。
- UI自動クリックで規約同意しない。
- 既存Node.jsやVS Codeを勝手にアンインストールしない。
- `-Force` があっても削除系操作はしない。
- Codex CLIのログイン情報やAPIキーは扱わない。

## ハッシュ検証

`config/software.json` に `expectedSha256` が設定されている場合は、実行前にSHA256を比較する。

- 一致: 続行
- 不一致: エラーで停止
- 未設定/空文字: 実測SHA256だけログに出して続行

## 管理者権限

MSI/EXEインストールで管理者権限が必要になる可能性が高いため、デフォルトでは管理者権限を要求する。

- 管理者でなければ自己再実行する
- `-NoElevate` 指定時は自己再実行せず、警告を出す
- `-DryRun` の場合は管理者でなくても続行してよい
